Linux基础知识

现在常见的操作系统：

PC端：

个人桌面操作系统：Windows macOS

服务器操作系统：Linux

移动端：

Android、IOS、鸿蒙系统

操作系统是计算机软件的一种，负责：

作为用户和计算机硬件之间的桥梁，调度和管理计算机硬件

Linux初识

系统组成：系统内核 + 系统级应用程序

内核：提供系统最核心的功能，如：调度CPU、调度内存、调度文件系统、调度网络通讯、调度IO

系统级应用程序：出厂自带程序，可供用户快速上手操作系统，如：文件管理器、任务管理器

内核网址：The Linux Kernel Archives

虚拟机

通过虚拟化技术，在电脑内，虚拟出计算机硬件，并给虚拟的硬件安装操作系统，即可得到一台虚拟的电脑，称之为虚拟机。

远程连接

使用Finalshell进行远程连接，添加ssh连接

查看Linux的IP地址：

1.桌面空白处点击右键，选择open in terminal

2.输入ifconfig，即可看到IP地址

中间遇到的问题：

才开始找不到ip地址，找到了相关方法操作后网络显示有问题，后来发现虚拟网络编辑器配置中缺少了VMnet8的相关配置，重新配了之后，添加NAT设置，添加端口转发，再用相关方法修改即可展示IP地址

显示IP地址的方法：

IP地址会刷新，因此在远程连接的时候一定要及其修改好IP地址

WSL

传统获取Linux操作系统环境要安装完整的虚拟机，使用WSL，可以非常轻量化的方式，得到Linux系统环境

WSL，全称Windows Subsystem for Linux，在Windows系统中获得Linux系统环境，并完全直连计算机硬件，无需通过虚拟机模拟硬件

直接在控制面板的应用与功能里面，找到启动或者关闭Windows功能，打开Linux子系统选项，安装Ubantu即可

虚拟机快照

学习阶段有损坏Linux操作系统的可能，如果损坏的话，重新安装比较麻烦。

因此通过快照将当前虚拟机环境保存下来，以后可以恢复到保存的状态。

Linux目录结构

Linux目录结构是一个树型结构

Linux没有盘符这个概念，只有一个根目录/，所有的文件都在它下面

路径举例：/user/local/hello.txt(第一个 / 是表示 根目录下 的意思)

Linux命令

通用格式：

command 命令本身

-options [可选，非必填]命令的一些选项，可以通过选项控制命令的行为细节

parameter [可选，非必填]命令的参数，多数用于命令的指向目标等

ls命令

作用：列出目录下的内容
